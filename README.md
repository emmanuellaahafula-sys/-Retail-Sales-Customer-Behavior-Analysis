# Retail Sales & Customer Behaviour Analysis

## Project Overview

This project analyzes retail sales and customer behaviour to understand business performance, identify sales trends, and generate actionable insights.

The project follows an end-to-end data analytics workflow using Excel, SQL Server, DAX, and Power BI to transform retail data into meaningful business insights.

## Business Questions

The analysis focuses on answering the following questions:

- Which products generate the most revenue?
- Who are the most valuable customers?
- What time of year has peak sales?
- Which regions underperform?
- Which product categories generate the most profit?

## Tools & Technologies

- **Excel** — Data cleaning, data preparation, and pivot analysis
- **SQL Server** — Data extraction, querying, and analysis
- **DAX** — Measures, calculations, and KPI development
- **Power BI** — Interactive data visualization and dashboard development

## Data Analysis Process

### 1. Excel

The dataset was prepared and reviewed in Excel. Data cleaning and preparation were performed to ensure the dataset was suitable for analysis.

### 2. SQL

SQL Server was used to query the dataset and answer key business questions, including product performance, sales trends, profitability, and regional performance.

### 3. DAX

DAX was used in Power BI to create calculated measures and KPIs for evaluating sales and profitability performance.

### 4. Power BI

The analyzed data was transformed into an interactive dashboard containing:

- KPI cards
- Product revenue analysis
- Profit by product category
- Sales performance by region
- Monthly sales trends
- Profit performance by region
- Interactive slicers for Order Date, Region, and Category

## Key Analysis

The project covers:

- Total revenue analysis
- Total orders analysis
- Total quantity sold
- Profit margin analysis
- Product performance
- Category profitability
- Monthly sales trends
- Regional sales performance
- Regional profitability
- Customer behaviour

## Dashboard

The Power BI dashboard provides a visual overview of retail sales and customer behaviour.

Users can interact with the dashboard using slicers to explore performance by:

- Order Date
- Region
- Category

## Key Insights

The analysis provides insights into:

- Top-performing products
- Monthly sales patterns
- Most profitable product categories
- Regional sales performance
- Regional profitability
- Customer purchasing behavior

These insights help identify areas of strong performance as well as areas that may require further investigation.

## Recommendations

Based on the analysis:

- Focus on high-performing products.
- Optimize inventory during strong sales periods.
- Review lower-performing product categories.
- Investigate underperforming regions.
- Use customer and sales data to improve business decisions.
- Align marketing and inventory strategies with observed sales trends.

## Conclusion

This project demonstrates an end-to-end data analytics workflow, from data preparation and SQL analysis to DAX calculations and Power BI dashboard development.

It shows how business data can be transformed into clear, interactive, and actionable insights to support data-driven decision-making.
